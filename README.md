# 立体几何绘图器

为**数学题配图**而做的立体几何绘图工具：从底面开始画，一键成柱 / 成锥，被遮挡的棱自动画成虚线；常用立体、截面、翻折、外接球 / 内切球、度量一键完成，还可以用文字让 AI 帮你作辅助线、辅助面。

## 运行

纯前端，无需安装、无需构建：

- 直接双击打开 `index.html`（Chrome / Edge / Firefox 均可）；或
- 在仓库目录运行 `npm start`（等价于 `npx http-server -p 8080`），然后访问 http://localhost:8080

## 主要功能

| 类别 | 功能 |
| --- | --- |
| 点 | 工作面 / 线段 / 面 / 圆 / 球面上单击建点（自动吸附网格、中点、三等分点）；坐标点；中点、任意比例点（如 2/5）；线上动点（可锁定为定点）；两线交点、线面交点；垂足、投影；对称点；垂直拉起点；定长动点；三角形四心 |
| 线 | 线段、连续线段、直线、射线；过点作垂线、平行线；延长线段 |
| 面 | 多边形（先画底面）；过三点的平面；平行于坐标面、过点垂直于直线、过点平行于平面、过直线垂直于平面、**过直线与平面成定角**的平面；切换工作面 |
| 模板 | 正方体、长方体、正棱柱、正棱锥、矩形底四棱锥、正棱台、正四面体、墙角三棱锥、鳖臑、堑堵、圆柱、圆锥、圆台、球；正三角形、直角三角形、等腰三角形、正方形、矩形、正多边形、平行四边形、菱形、梯形、圆。参数可随时修改 |
| 由底面生成 | 拉伸成直棱柱、斜棱柱、收成锥（中心上方 / 指定顶点）、棱台；由若干点生成凸多面体（自动虚实） |
| 球 | 外接球、内切球、棱切球（不存在时给出提示）；过四点的球；球的截面圆；球面与多面体表面的交线及总长；三种显示方式：明暗立体（可调不透明度）、轮廓 + 赤道、经纬线（可调疏密） |
| 截面 / 翻折 | 立体被平面所截的截面（交点自动命名）；翻折（选择面或三点 + 折痕，角度滑块与动画） |
| 度量 | 长度、点线距、点面距、异面直线距离、平面角、异面直线所成角、线面角、二面角（两面 / A-BC-D）、面积、体积、表面积、圆周 / 交线长、球的半径表面积体积；**精确值识别**（如 √6/3、2√3/3、4π）；**"修改为…"反向修改图形**（如把二面角改成 50°） |
| 轨迹 | 追踪任意点的轨迹；摇杆控制动点；参数动画；扫描参数一键生成完整轨迹 |
| 标注 | 直角标记、角弧；每个对象都有名称，标签默认隐藏，可单独显示或一键全部显示（L 键），标签可拖动；**单击图中的任何文字**可编辑、隐藏、添加到左上角面板 |
| 文字 | “文字”工具（T 键）：单击点 / 线 / 空白处放置文字，文字跟随该点或线；可**插入变量**（长度 `{len:A,B}`、角 `{ang:A,B,C}`、坐标、度量、参数），随图形实时变化，可选精确值（如 2√3）或小数 |
| 控制 / 左上角面板 | 右侧“控制”标签页：**新建控件**（滑动条、按钮、开关、文字），也可让 AI 设计；控件、题目按钮、文字都可以**上屏**到画布左上角的浮动面板（不随图形旋转，可折叠、拖动，位置会记住）；导出图片时可选择附带面板中的文字 |
| 显示 | 正投影（可任意旋转）/ 斜二测；坐标轴、刻度、底面网格、立体网格、点坐标，均可勾选；被遮挡线：虚线 / 隐藏 / 实线 |
| 文件 | 自动保存到浏览器；保存 / 打开 `.json`；导出 PNG、SVG（矢量，适合 Word）、复制图片 |
| 从题目新建 | “新建 → 从题目新建”：粘贴题目文字或上传 / 粘贴题目截图（含示意图）→ AI 识别 → **确认面板**中可修改所有信息（数据、动点、题目要求、补充说明）→ 自动画图。识别与画图可分别选择模型、是否思考、思考强度。题目中的动点一定生成为可拖动、可动画的动点 |
| 题目控制面板 | 右侧“题目”标签页：动点滑块与播放、AI 为本题设计的演示按钮（由“积木”动作组成：设参数、播放动画、跳到最值、显示 / 隐藏、作辅助图、转视角、轨迹、说明文字、度量）、**与原图同视角**（由示意图中各点位置反推视角）。求最值时 **AI 与程序各算一次**并显示是否一致，不一致可**一键检查问题**并应用修正（格式见 docs/problem-panel.md） |
| 视角 | 右下角视角控制器：坐标轴指示器、旋转摇杆、15° 按钮、转到背面、复位；可翻过头顶连续转动；**视角基准面**（以任意面为“地面”旋转，可放平 / 正对）；手机平板双指缩放、平移 |
| AI | 设置中填写 API Key（默认 DeepSeek；模型用下拉框选择 Flash / Pro，也可自定义，或改为 OpenAI 等兼容接口）。面板中一键开启 / 关闭思考（DeepSeek 通过 `thinking` 参数切换，思考强度可在设置中选择）。**作图模式**：当前图形自动以 JSON 发送给模型，模型返回作图指令（以及按需设计的控件）后直接画出（可撤销，出错可一键让 AI 修正）；**对话模式**：只交流，AI 能看到当前图形但不作图。可勾选**附带当前题目**；**新对话**、**对话记录**（切换、删除、清空，保存在本机浏览器） |

## 使用方法速览

1. **旋转**：左键拖动空白处（或右键拖动）；**平移**：Shift + 拖动；**缩放**：滚轮。
2. **画图顺序**：先画底面（模板或"面 → 多边形"），再"拉伸成柱 / 收成锥"。要在其他面上画点，先切换**工作面**（工具选项条右侧），或直接在立体的面上单击。
3. **选中对象后**，画布下方的**快捷操作**会列出可做的事：两个点 → 连线 / 中点 / 测距离；立体 → 外接球 / 内切球 / 体积；直线 + 平面 → 线面角 / 交点 / 成角平面……
4. 右侧**属性**面板可修改名称、样式、参数（滑块拖动实时变化，▶ 播放动画）。

## 目录结构

```
index.html            页面
css/style.css         样式
js/core/              几何核心（无 DOM 依赖，可在 Node 中测试）
  vec.js              向量与几何算法（凸包、最小二乘、Nelder-Mead…）
  exact.js            精确值识别（√、分数、π）
  style.js            默认样式
  scene.js            场景模型：对象、构造定义（依赖图）、求值、序列化
  solids.js           立体 / 平面图形模板，外接球、内切球、棱切球
  measure.js          度量、反向求解
  commands.js         命令层（界面工具、快捷操作、AI 共用）
js/ai/problem.js      从题目新建：识别 / 生成提示词、最值扫描与核实、对齐示意图视角
js/render/            相机（正投影 / 斜二测）、消隐渲染、Canvas / SVG 输出
js/ui/                界面：工具定义、交互、快捷操作、面板、摇杆、AI 面板
js/ai/                AI 提示词、场景描述、指令执行、接口客户端
docs/commands.md      作图指令参考（AI 与"指令"窗口使用）
docs/problem-panel.md 题目控制面板（按钮动作、最值核实）格式
tests/                测试（npm test 运行核心测试；npm run test:ui 运行浏览器测试，需要 Playwright）
```

## 扩展

- **新增一种构造**（如新的点的作法）：在 `js/core/scene.js` 用 `reg(kind, {type, deps, eval, params})` 注册，再在 `commands.js` 加一个 `op_xxx` 命令，界面工具在 `js/ui/tools.js` 中用 `tool({...})` 声明即可（声明需要用户依次选择什么、选项、执行什么命令）。
- **新增模板**：在 `js/core/solids.js` 的 `T` 中添加 `{label, params, build, names}`，并加入 `tools.js` 的 `TPL3 / TPL2` 列表。
- **AI 能力**：命令层的新命令写入 `js/ai/prompt.js` 的系统提示词，AI 即可使用。

所有脚本都是普通 `<script>`（挂在全局 `SG` 命名空间下），因此直接用文件方式打开即可运行。
